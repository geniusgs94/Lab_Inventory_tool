❯ what does this project do?

⏺ This is a Lab Inventory Management Tool — a web app for tracking lab devices
  (like computers, network equipment, etc.) shared across a team.

  Key features:

  - Login system with two roles — admin and user, with a 15-minute session
  timeout
  - Device inventory — each device tracks: MAC address, IP address, device
  model, owner, team, reporting manager, location, and lease info
  - Search & filter — search across all fields, filter by availability status
  - Device lifecycle actions:
    - Add a new device
    - Edit — only the device owner or an admin can edit; MAC, model, owner, and
  lease are locked (read-only after creation)
    - Reserve — claim an available device (marks it "In Use")
    - Release — return a device you own back to "Available"
    - Request — notify the owner that someone wants to use their device
    - Delete — admins can delete anything; users can only delete their own or
  available devices
  - Change history log — every reserve, release, and delete action is recorded
  with who did it and when
